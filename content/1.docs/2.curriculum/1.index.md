The syllabus was never the secret. What is missing at most colleges is a teacher
who connects the subject to the job — that connection is what these courses are.

## Module 0 — How the IT Industry Works · `CS-000` · 2 weeks

Mandatory for everyone, cannot be deselected, always first. What software is,
what the industry is, product vs service companies, the teams, a day in the life,
and the vocabulary every team assumes you already have.

## Module 1 — Computer Science Foundations · ~20 weeks

**Semester 1 · The Machine**
- **Operating Systems** `CS-OS-101` · 4 wk — processes and threads, scheduling, memory and paging, deadlocks, concurrency, file systems, the Linux you will use daily.
- **Computer Networks** `CS-NET-101` · 3 wk — IP, ports, DNS, TCP vs UDP, HTTP, what happens when you type a URL, REST, caching, TLS and CORS.

**Semester 2 · The Data**
- **DBMS** `CS-DB-101` · 3 wk — the relational model, schema design, normalisation and when to stop, keys, SQL, indexes, transactions and ACID, SQL vs NoSQL honestly.

**Semester 3 · The Code**
- **Object-Oriented Programming** `CS-OOP-101` · 3 wk — taught in your chosen language, with real reasons rather than definitions.
- **Data Structures & Algorithms** `CS-DSA-101` · 6 wk — complexity briefly and honestly, then the structures and patterns that actually appear.

**Semester 4 · The Craft**
- **Software Engineering** — SDLC, agile in practice, version control, testing, code review, CI/CD.
- **Web Technologies** — how the web actually works before any framework touches it.

**Semester 5 · The Scale**
- **System Design** — the entry-level version: load balancers, caching, queues, and how to answer the question without bluffing.
- **AI overview** — what these tools are, what they are not, and how to use them without outsourcing your understanding.
- **Theory of Computation** — the short, honest version.

## Module 2 — Your Programming Language · 12 weeks, in parallel

Java by default. C/C++, Python or TypeScript on request. One language, taken all
the way to the point where you can read somebody else's codebase.
