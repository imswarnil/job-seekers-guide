---
title: The platform is now markdown, all the way down
description: Rebuilt on Nuxt with folder-based content. Courses are directories, lessons are files, and the documentation and the course player read the same tree.
date: 2026-08-17
---

The platform has been rebuilt from the ground up as a Nuxt application with
file-based content. There is no database and no admin screen, because there no
longer needs to be one.

## What changed

- **Courses are folders.** A course is a directory, a module is a directory inside it, and a lesson is a markdown file. The tree on disk is the curriculum.
- **One tree, two readings.** The documentation sidebar and the course player consume the same navigation structure, so a course cannot drift out of sync with its syllabus.
- **A real player.** Lessons open in a focused reader with the module contents on the left, the section outline on the right, and progress that survives a closed tab.
- **Progress is local and private.** Completion is stored in your browser. Nothing is uploaded, and no account is required to use the whole path.
- **Editing is markdown.** Every lesson is plain text in git, whether it was written in an editor or in a pull request.

## What stayed

The design language — indigo for structure, teal for the accent, amber rationed
for milestones, neutrals tinted toward the brand hue — carried over intact, and
now lives as design tokens rather than as a stylesheet.

## What is next

Writing the curriculum. The platform runs; the courses are the work.
