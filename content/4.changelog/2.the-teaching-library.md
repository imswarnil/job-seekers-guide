## The path

Courses and docs were two ways of saying the same thing. There is one path a job
seeker walks, so there is now one path in the site. Subjects live at the root:
`/operating-systems` is a subject, `/operating-systems/processes-and-threads` is
a module, and the lesson inside it is one segment further down. No `/courses`
prefix, and no separate documentation section.

The change that makes it a path rather than a catalogue is that **next** and
**previous** run across the whole platform. The last lesson of Operating Systems
goes forward into Databases; the first lesson of a subject goes back into the one
before it. The player says which, so crossing a boundary reads as progress rather
than as the end of something.

## The player

The lesson page is now a player rather than a documentation page: a rail showing
the whole path with the subject you are in opened, a footer bar with previous,
mark-finished, position and next, keyboard control — `j`, `k`, `m`, `[` — and an
opt-in auto-advance that any keypress cancels.

Progress moved from per-course to the whole path, and everything saved under the
old scheme was migrated rather than dropped.

## Teaching components

Lessons can now use flow diagrams, code walkthroughs that step down a code block
one highlighted region at a time, memory and data-structure drawings,
before-and-after comparisons, honest pros-and-cons panels, personas, timelines,
copyable AI prompts, videos that cost nothing until played, and code the reader
can run in Python, SQL, JavaScript, HTML, CSS or Java.

All of them are markdown, all of them share one visual and motion language, and
all of them still make sense with JavaScript switched off — a code walkthrough
degrades to the code plus a numbered list of captions rather than to an empty box.

There is a page showing every one of them:
[How these lessons are built](/how-the-industry-works/the-vocabulary/the-teaching-components).

## What stayed

Free, no account, progress in your browser and nowhere else, no placement claims.
Every old `/courses` and `/docs` link still resolves.
