Courses and docs were two ways of saying the same thing. There is one path a job
seeker walks, so there is now one path in the site.

The change that makes it a path rather than a catalogue is that next and
previous index into every lesson on the platform. Crossing from Operating
Systems into Databases reads as progress rather than as the end of something.

Every teaching component still makes sense with JavaScript switched off — a code
walkthrough degrades to the code plus a numbered list of captions, not an empty
box.
