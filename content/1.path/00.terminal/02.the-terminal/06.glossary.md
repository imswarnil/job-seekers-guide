The short way to find out whether they are yours is to cover the right-hand
column of the next table and say what each command does. Anything you hesitate on
goes on a sticky note.

## Why this matters in a job

Because nobody memorises these from a list — they memorise them by needing them
forty times. This page exists so that the fortieth time is quick, not so that you
can revise. Keep it in a tab.

## The commands, in one line each

**Where you are, and what is there**

| Command | What it does |
| --- | --- |
| `pwd` | Print the folder you are currently in |
| `ls` | List what is here |
| `ls -l` | Long form: permissions, owner, size, date |
| `ls -la` | The same, including hidden dot-files |
| `cd folder` | Go into a folder |
| `cd ..` | Up one level |
| `cd ~` | Home, from anywhere |
| `cd -` | Back to where you just were |

**Making and destroying**

| Command | What it does |
| --- | --- |
| `mkdir name` | Make a folder |
| `mkdir -p a/b/c` | Make the whole chain, parents included |
| `touch file` | Create an empty file |
| `cp a b` | Copy. Source first, destination second |
| `cp -r a b` | Copy a folder and everything in it |
| `mv a b` | Move — and, in the same folder, rename |
| `rm file` | Delete a file. No bin, no undo |
| `rm -r folder` | Delete a folder and its contents |
| `rm -rf folder` | The same, forced and silent. Check with `ls` first |

**Reading and searching**

| Command | What it does |
| --- | --- |
| `cat file` | Print the whole file |
| `less file` | Scrollable view. `/` to search, `q` to quit |
| `head -n 20 file` | First 20 lines |
| `tail -n 20 file` | Last 20 lines |
| `tail -f file` | Follow a file as it is written. `Ctrl + C` stops |
| `grep "text" file` | Print lines containing that text |
| `grep -in "text" file` | Case-insensitive, with line numbers |
| `grep -rn "text" .` | Search every file below here |
| `grep -v "text" file` | Lines that do **not** match |
| `wc -l file` | Count lines |
| `sort` / `uniq -c` | Sort, then count adjacent duplicates. Always in that order |
| `cut -d, -f3` | Take the third comma-separated column |
| `grep x file \| sort` | A pipe. Feeds the output of one command into the next |
| `> file` | Write output to a file, overwriting it |
| `>> file` | Append output to a file |

**Permissions, users, processes**

| Command | What it does |
| --- | --- |
| `whoami` / `id` | Who you are, and which groups you are in |
| `chmod +x file` | Make it executable |
| `chmod 755 file` | Owner everything, others read and execute |
| `chmod 644 file` | Owner read and write, others read |
| `chown user file` | Change who owns it |
| `sudo command` | Run one command as the administrator |
| `ps aux` | Every running process |
| `lsof -i :3000` | What is listening on that port |
| `kill 4821` | Ask a process to stop |
| `kill -9 4821` | Make it stop, with no chance to clean up |
| `top` | Live view of processor and memory use |

**Other machines**

| Command | What it does |
| --- | --- |
| `ssh user@host` | Open a shell on another machine |
| `ssh-keygen -t ed25519` | Generate a key pair |
| `exit` | Leave a remote session |
| `ping host` | Is it reachable, and how far away |
| `curl -i url` | Fetch a URL and show the response headers |

**Keys that save you**

| Key | What it does |
| --- | --- |
| `Tab` | Complete the name you are typing |
| `↑` | The previous command |
| `Ctrl + C` | Stop what is running |
| `Ctrl + D` | End input, or log out |
| `Ctrl + L` | Clear the screen |
| `q` | Get out of `less`, `top` and most full-screen viewers |

## The words

::field-group
  ::field{name="Shell" type="terminal"}
  The program that reads what you type and runs it. Bash and zsh are the two you
  will meet. The terminal is the window; the shell is the thing inside it.
  ::

  ::field{name="Prompt" type="terminal"}
  The line the shell prints when it is ready. It usually tells you the user, the
  machine and where you are.
  ::

  ::field{name="Path" type="terminal"}
  A route through the folder tree. **Absolute** starts at `/` and means the same
  from anywhere; **relative** is resolved from where you currently are.
  ::

  ::field{name="Root" type="terminal"}
  Two meanings, unhelpfully. `/`, the top of the filesystem — and the
  administrator user who is exempt from permission checks.
  ::

  ::field{name="Flag / option" type="terminal"}
  Extra instruction after a dash: `-l`, `-r`, `-rf`. Single-letter flags combine.
  ::

  ::field{name="Pipe" type="terminal"}
  `|`. Feeds one command's output into the next. The idea the whole toolset is
  built around.
  ::

  ::field{name="Redirect" type="terminal"}
  `>` sends output to a file, replacing it. `>>` adds to the end.
  ::

  ::field{name="Hidden file" type="terminal"}
  Any name beginning with a dot. Not secret — just left out of `ls` unless you
  ask for `-a`. `.git`, `.env` and `.gitignore` all matter enormously.
  ::

  ::field{name="Permission bits" type="terminal"}
  The ten characters at the start of an `ls -l` line: type, then read/write/execute
  for owner, group and everyone else.
  ::

  ::field{name="Process id (PID)" type="terminal"}
  The number the operating system knows a running process by. What `kill` takes.
  ::

  ::field{name="Port" type="terminal"}
  A numbered door on a machine. One process at a time may listen on one port,
  which is why `EADDRINUSE` happens.
  ::

  ::field{name="SSH" type="terminal"}
  Secure shell — an encrypted connection giving you a prompt on another machine.
  ::

  ::field{name="Key pair" type="terminal"}
  A private key that never leaves your machine and a public key you hand out.
  Proves who you are without sending a secret.
  ::
::
