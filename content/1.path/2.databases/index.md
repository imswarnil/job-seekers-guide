## Why this subject

Because the data outlives the code. Frameworks get replaced; the admissions table
designed badly in year one is still there in year five, with every reporting bug
downstream of it.

::callout{icon="i-lucide-construction" color="warning"}
This course is being written. The first lesson is live; the remainder follows the
outline in [the curriculum](/path).
::
