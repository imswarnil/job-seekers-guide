# Personas

Everyone here shares one goal — **get a job in software** — but they arrive from
different places, with different gaps and different fears. The onboarding flow
exists to figure out which of these a new user is, and to assemble their path
accordingly.

## How personas map to paths

The onboarding answers — degree, branch, self-assessed level, target role — are
what actually select the path. Persona names are our shorthand for the common
clusters, not a field the user ever sees.

```
degree + branch ──┐
self-assessed level ──┼──▶ starting module ──▶ assembled path
target role ──┘
```

Every path, regardless of persona, begins with the same module:
**How the IT Industry Works.** See [../curriculum/00-how-it-works.md](../curriculum/00-how-it-works.md).
