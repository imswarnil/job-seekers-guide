# Module 2 — Your Programming Language

**Duration:** ~12 weeks, running **in parallel** with the foundation semesters
from week 3 onward. Reading about OOP while writing OOP is how it sticks.

One language. Chosen at [step 6](../flows/06-language-selection.md). Learned
properly.

## The shared shape

Every language track follows the same nine stages, so a learner who switches
languages loses ordering, not understanding:

| Stage | What |
|---|---|
| 1 | Setup — install it, run your first program, use an IDE |
| 2 | Basics — variables, types, operators, input/output |
| 3 | Control flow — conditions, loops, and the bugs they cause |
| 4 | Functions — parameters, returns, scope, decomposition |
| 5 | **OOP in this language** — pairs with `CS-OOP-101` |
| 6 | Collections & data structures — the built-in ones you'll use daily |
| 7 | Files, errors, exceptions — programs that don't crash |
| 8 | **Talking to a database** — pairs with `CS-DB-101` |
| 9 | Build something real — the language's project |

## ☕ Java · `LANG-JAVA-101` — recommended

**Why it's the default recommendation for Indian job seekers:** the largest
fresher hiring market by a wide margin. TCS, Infosys, Wipro, Accenture,
Capgemini, Cognizant, HCL — all hire Java at volume, every year. It is strict
enough that it teaches you OOP properly instead of letting you dodge it. And
most Indian college syllabi already brush against it, so it starts warm.

**Course sequence**
1. Java setup — JDK, IDE, your first program, how compilation works
2. Syntax, types, operators
3. Control flow and loops
4. Methods, and structuring code
5. **OOP in Java** — classes, objects, inheritance, interfaces, polymorphism,
   abstract classes
6. Collections framework — List, Set, Map, and when to use which
7. Exceptions, file I/O
8. **JDBC** — connecting Java to MySQL
9. Build: a console-based library management system
10. Onward — Spring Boot, Maven, Hibernate (bridges to the web track)

## 🐍 Python · `LANG-PY-101`

**Pick it if:** you're aiming at data, ML, automation, or QA scripting — or you
want the gentlest possible start.

1. Setup and your first script
2. Syntax, types, dynamic typing
3. Control flow
4. Functions, and Pythonic style
5. **OOP in Python**
6. Lists, dicts, sets, tuples, comprehensions
7. Files, exceptions, modules, virtualenv, pip
8. **Talking to a database** — sqlite3, SQLAlchemy basics
9. Build: a CLI expense tracker
10. Onward — pandas, FastAPI/Django (bridges to data or web)

## 🔷 TypeScript / JavaScript · `LANG-TS-101`

**Pick it if:** you want the browser, want to *show* people something fast, or
are aiming at startups.

1. JavaScript in the browser and in Node
2. Syntax, `var`/`let`/`const`, types
3. Control flow, arrays, objects
4. Functions, closures, arrow functions
5. **OOP + TypeScript types, interfaces, generics**
6. Arrays, maps, sets, destructuring, spread
7. Async — callbacks, promises, async/await, error handling
8. **Talking to a database** — Node + Postgres/MySQL
9. Build: a task API with a small frontend
10. Onward — React, Node/Express, Next.js

## ⚙️ C / C++ · `LANG-CPP-101`

**Pick it if:** you want systems, embedded, game dev, or competitive
programming — or you want to understand what every other language is hiding.

1. Setup, compilation, your first program
2. Syntax, types, operators
3. Control flow
4. Functions, and **pointers & memory** (the reason to learn this)
5. **OOP in C++** — classes, constructors, destructors, RAII
6. Arrays, strings, STL — vector, map, set
7. Files, error handling, memory management
8. **Talking to a database** — briefly; C++ is rarely the DB layer
9. Build: a data-structure library, implemented from scratch
10. Onward — competitive programming with C++ STL (pairs well with `CS-DSA-101`)

## Rules across all tracks

1. **Type every line.** Watching a video does not teach a language.
2. **Break it deliberately.** Change something, predict the error, check.
3. **Debugger before print statements** — taught in stage 4 of every track.
4. **The second language is free.** Two weeks, once the first is solid. Never
   start it before then.
