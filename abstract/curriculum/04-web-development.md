# Module 4 — Web Development

**Course codes:** `WEB-201` (frontend), `WEB-202` (backend), `WEB-203` (deploy)
**Duration:** 6 weeks · **Default applied track**

The default because it has the largest job market, produces something you can
*show* people fastest, and pivots into every other track cheaply.

## `WEB-201` — Frontend · 2 weeks

1. HTML that means something — semantic tags, forms, accessibility basics
2. CSS fundamentals — the box model, specificity, the cascade
3. Layout — flexbox and grid, until layout stops being guesswork
4. Responsive design — mobile-first, media queries, real device testing
5. JavaScript and the DOM — selecting, events, updating the page
6. Fetching data — fetch, async/await, rendering an API response
7. Browser dev tools — the single highest-leverage skill in this course
8. A framework (React) — components, props, state, effects, routing
9. Forms, validation, and the errors users actually make
10. Build: a responsive multi-page site consuming a real API

## `WEB-202` — Backend · 3 weeks

1. What a server does, concretely
2. Your first server — Spring Boot / FastAPI / Express, by language
3. Routing and HTTP methods
4. **REST API design** — resources, status codes, versioning, what good looks
   like
5. Request validation and error handling
6. Connecting to the database (from Module 3)
7. **CRUD, end to end** — the shape of most working software
8. **Authentication** — sessions vs JWT, password hashing, why you never store
   plaintext
9. Authorization — roles and permissions
10. File uploads
11. Environment config and secrets — and why they never go in Git
12. Logging and debugging a running server
13. Testing your API — Postman, then automated tests
14. Build: a complete REST API with auth, backed by a real database

## `WEB-203` — Shipping it · 1 week

1. Git and GitHub, properly — branches, PRs, conflicts, a clean history
2. Environments — dev, staging, production
3. Deploying — a VPS or a platform host, a real domain, HTTPS
4. Environment variables in production
5. CI/CD — tests and deploy on push
6. Monitoring, logs, and what to do at 2am
7. Performance — caching, compression, image handling
8. Security basics — OWASP top 10 for someone who ships for the first time
