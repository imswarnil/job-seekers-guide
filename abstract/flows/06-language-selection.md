# Step 6 — Choose one programming language

## The screen

> ### Pick one language. One.
> You will learn it properly — from syntax to building real things with it.
> Learning four languages badly is the most common way to waste a year.

Four cards, single selection:

### ☕ Java — recommended
> **Why we recommend it:** the largest fresher job market in India by a wide
> margin. Every service company — TCS, Infosys, Wipro, Accenture, Capgemini,
> Cognizant — hires Java at scale. It's strict, which means it teaches you OOP
> properly instead of letting you avoid it. And it's the language most Indian
> college syllabi already gesture at, so some of it will feel familiar.
>
> **Leads to:** Backend Developer, Full-Stack, Android, Enterprise/Salesforce
> **Pairs with:** Spring Boot, Hibernate, Maven

### 🐍 Python
> **Why pick it:** easiest to start with, and the default language of data and
> AI. If your target is Data Engineer, Data Analyst, ML, or automation/QA
> scripting, choose this.
>
> **Leads to:** Data Engineer, Data Analyst, ML, DevOps scripting, QA automation
> **Pairs with:** Django/FastAPI, pandas, SQL

### 🔷 TypeScript / JavaScript
> **Why pick it:** the only language that runs in the browser, so it's
> unavoidable if you want to build web interfaces. Fastest route to something
> you can *show* people. Startups hire it heavily.
>
> **Leads to:** Frontend, Full-Stack, Node backend
> **Pairs with:** React, Node.js, Next.js

### ⚙️ C / C++
> **Why pick it:** closest to the machine. Teaches memory, pointers, and how
> things actually work. Preferred for competitive programming, systems,
> embedded, and gaming — but a smaller fresher job market for web/enterprise
> work.
>
> **Leads to:** Systems, Embedded, Game Dev, Competitive Programming
> **Pairs with:** DSA (C++ is the standard choice for interview practice)

## Sidebar copy

> **Why one, and why so firmly?**
>
> Because the second language takes two weeks once you know the first one
> properly, and because "knows a bit of five languages" on a resume reads as
> "knows none of them" to an interviewer. Syntax is the easy part; the hard part
> is thinking in code, debugging, structuring a program — and those transfer
> completely.
>
> **Not sure?** Take Java. If it turns out to be wrong for your track, you'll
> know that in month two, and everything you learned will carry across.
>
> **Already know one?** Pick it and go deeper rather than starting a new one.

## Interaction with earlier steps

If the user picked a target role at step 4, the matching language card is
**pre-highlighted** with a note — but Java stays labelled "recommended" as the
general default, and the user can always override.

| Target role | Pre-highlighted |
|---|---|
| Data Engineer / Analyst / ML | Python |
| Frontend / Full-Stack | TypeScript |
| Backend / Salesforce / Android | Java |
| Systems / Embedded / Game | C/C++ |
| Help me decide | Java |

## What follows

The chosen language becomes a **full course track**, running in parallel with
the foundation semesters — not after them. Reading about OOP while writing OOP
is how it sticks.

```
Basics & syntax → Control flow → Functions → OOP in this language →
Collections/data structures → File & error handling → Working with a database →
Build something small → Build something real
```
