# Step 7 — Choose your track

The applied layer that sits on top of the foundations and your language.

## The screen

> ### What do you want to build?
> This decides your projects and your applied courses. The foundations
> underneath stay the same — which is why changing your mind later costs you
> weeks, not years.

| Track | You'll learn | You'll build | Roles |
|---|---|---|---|
| 🌐 **Web Development** *(default)* | HTML/CSS/JS, a framework, REST APIs, auth, deployment | Portfolio, blog CMS, e-commerce, full-stack app | Frontend, Backend, Full-Stack |
| 📊 **Data** | SQL deep, Python data stack, pipelines, warehousing, visualisation | Dashboard, ETL pipeline, analysis report | Data Analyst, Data Engineer |
| ☁️ **DevOps / Cloud** | Linux, Git, CI/CD, Docker, cloud basics, monitoring | Deploy pipeline, containerised app, infra scripts | DevOps, Cloud, SRE |
| 🧪 **QA / Test Automation** | Testing theory, Selenium/Playwright, API testing, frameworks | Automated test suite, API test harness | QA Engineer, SDET |
| 📱 **Mobile** | Android (Java/Kotlin) or React Native, app lifecycle, storage | Two published apps | Android/iOS Developer |
| 🏢 **Enterprise / Salesforce** | Salesforce platform, Apex, admin + dev certs, low-code | Configured org, custom app | Salesforce Dev/Admin |
| 🤖 **AI / ML basics** | What ML is, using AI APIs, building on top of models | AI-powered app | AI-adjacent product roles |

**Multi-select is allowed for at most two tracks**, with a warning:

> Two tracks means roughly 1.5× the time. Fine if you have it. If you're
> job-hunting now, take one — depth in one track beats breadth in two, every
> time.

## Sidebar copy

> **Salesforce is on this list for a personal reason.** It's how I got into
> Accenture in 2017, three months after taking a ₹13,000/month job. Enterprise
> platform tracks get dismissed as "not real coding" by people on the internet,
> and they pay very well, hire freshers steadily, and have far less competition
> than web development. Consider it seriously.

> **Web Development is the default** because it has the largest job market, the
> lowest barrier to a visible portfolio, and the easiest pivot into any of the
> others afterwards.

## Track selection is deferred for "Help me decide"

If the user chose *"Help me decide"* at step 4, this screen shows:

> We'll come back to this. Finish Module 0 first — it'll show you what each of
> these people actually does on a Tuesday, and then this choice will be obvious
> instead of a guess. Web Development is set as your default in the meantime.

The step is re-presented as a dashboard prompt when Module 0 completes.

## Projects per track

Every track produces **four projects**, escalating:

| # | Shape | Purpose |
|---|---|---|
| 1 | Guided, follow-along | Confidence — the first thing that works |
| 2 | Guided with variations | Understanding — change it and see what breaks |
| 3 | Spec only, you build it | Independence — a resume project |
| 4 | Your own idea, reviewed | Ownership — the one you'll talk about in interviews |

See [../curriculum/06-projects.md](../curriculum/06-projects.md).
