# Step 3 — Where are you now?

The single most important question in the wizard. It sets the starting module
and the pacing for everything after.

## The screen

> ### Where should we start you?
> Answer honestly. There is no wrong answer here and nobody sees this but you.

Four large cards, one selection:

### 🌱 Start me from the very beginning
> I don't know what software or IT really is. I've never written code, or I've
> only seen it in class. Teach me like I know nothing.

**→ Level 1.** Full Module 0, full foundations, gentlest pacing, no assumed
vocabulary.

### 🌿 I know a little
> I've studied some CS in college or online. I recognise the terms — OOP,
> database, loops — but I can't build anything on my own yet.

**→ Level 2.** Module 0 short version, foundations taught application-first,
normal pacing. *Most CS graduates belong here even if they think otherwise.*

### 🌳 I can code, I can't get hired
> I can build small things. My problem is interviews, resume, and knowing what
> companies actually want.

**→ Level 3.** Foundations as targeted revision, straight into System Design,
projects, and the full job-search track.

### 💼 I'm already working, I want a better job
> I have a job in IT or elsewhere. I want to switch — to a better role, a
> better company, or better pay.

**→ Level 4.** Depth + System Design + the Offer & Switch module, on
part-time-realistic pacing.

## Sidebar copy

> Most people underestimate this question in one direction and overestimate it
> in the other. If you finished a CS degree but can't build an app without
> following a tutorial line by line — pick **"I know a little."** That's not an
> insult. That's most graduates, and it's exactly the gap this platform was
> built to close.
>
> You can change this any time. If a module feels too easy, skip it. If it feels
> too hard, drop a level. Nothing is locked.

## What this does not do

- It does **not** skip Module 0 for anyone. Level 3 and 4 users get a condensed
  version, but *"how the IT industry works"* is never removed — it's the module
  most self-taught people are missing without knowing it.
- It does **not** lock the user in. Every module is visible; the level only
  decides what's *recommended* and pre-selected.

## Optional: the honesty check

For users who select Level 3 or 4, offer a **short optional self-check** (5
questions, no score shown publicly, no time limit) with the framing:

> Want to sanity-check that? Five questions, two minutes. We'll suggest a level
> — you can ignore us.

Never mandatory. Never a gate. A learner who feels tested at step 3 leaves.
