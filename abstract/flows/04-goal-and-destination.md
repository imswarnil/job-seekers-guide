# Step 4 — Where do you want to reach?

## The screen

> ### What are you aiming for?
> Pick the closest one. You are allowed to change your mind — most people do,
> and Module 0 exists to help you decide properly.

### Primary goal (one of)

| Option | Meaning |
|---|---|
| 🎯 **My first job in IT** | Fresher, no offer yet |
| 🔄 **Switch into IT from another field** | Career changer |
| 📈 **A better job than the one I have** | Early-career switcher |
| 🧭 **I don't know yet — help me figure it out** | Explicitly allowed, and common |

### Target role (optional)

> Already know what you want to be? Pick it. If not, choose **"Help me decide"**
> — Module 0 will walk you through what each of these people actually does all
> day, and you can come back and pick then.

- Software / Backend Developer
- Frontend / Web Developer
- Full-Stack Developer
- Data Engineer
- Data Analyst / Data Scientist
- QA / Test Automation Engineer
- DevOps / Cloud Engineer
- Mobile Developer (Android / iOS)
- Salesforce / Low-code Developer
- Business Analyst / Product
- Support / Implementation Engineer
- **🤔 Help me decide** ← default

## Sidebar copy

> **Read this before you pick.**
>
> There are N number of tools, N number of roles, and N number of "must-learn"
> lists on the internet. They contradict each other because they're written by
> people who took different routes to the same place.
>
> Here's the thing they don't tell you: **the foundation is the same for all of
> them.** Operating systems, databases, networks, how programs are structured,
> how to think about a problem. A backend developer and a data engineer and a
> DevOps engineer all stand on that same floor.
>
> So picking your role today is useful, but it is not urgent — and it is not
> final. What matters is that you start building the floor while you decide what
> to put on top of it.

## What this step controls

| Answer | Effect |
|---|---|
| Goal | Whether the Offer & Switch module is fresher-flavoured or experienced-flavoured; resume module variant |
| Target role | Which foundations get extra weight, which language is recommended, which track is preselected at step 7, which projects are suggested |
| "Help me decide" | Adds the **Role Reality Check** lesson set to Module 0, and defers the track choice until after it |

## The "Help me decide" branch

This is not a dead end — it is a designed route:

```
Help me decide
      ↓
Module 0 (extended): What is software → What an IT company contains →
What each team does all day → Roles, in plain language, with real daily
routines and honest salary ranges
      ↓
"Now pick" screen, re-offered at the end of Module 0
      ↓
Track selection unlocks, path recomposes
```

A user who reaches the end of Module 0 and still can't choose is defaulted to
the **Web Development track** — the broadest entry point, the largest job
market, and the easiest to pivot out of later.
